About

On the ground with hardware nobody's seen yet.

I've spent the last 15+ years in the dark. Blind. Gesticulating wildly (occasionally in public) in an attempt to make software behave. Gentle encouragements to ensure creative design matches developed delivery. My core skill is the ability to effectively communicate what I see, how to replicate the issue, and constructively feedback this information.

I'm a geek. I love tech. Love my role. The opportunity to explore cutting-edge hardware and software is a treat, and the variety of working flexibly across different locations and teams makes long days feel short.

Equally comfortable in an Agile sprint or a Waterfall plan, I build boutique ad hoc test suites where a project calls for it, or work within industry-standard software such as TestRail, Xray, and Zephyr. I'm a veteran in Jira and Trello, and well-versed in building to device and catching performance issues early using the profilers and loggers in Unity, Xcode, Android Studio, Meta Developer Hub, and Lens Studio.

Throughout my career I've been trusted with high-profile projects for names like Disney, Meta, and Snap.

What profiling catches
Unity Profiler — CPU / GPU / memory
  • Garbage collection spikes causing frame hitches
  • Excessive draw calls and batching failures
  • Texture and mesh memory bloat
  • Shader compilation stalls on first run
Xcode Instruments — iOS / visionOS
  • Memory leaks and retain cycles
  • Thermal state throttling under load
  • Energy log battery drain outliers
  • Metal GPU overdraw and shader bottlenecks
Android Studio Profiler — CPU / memory / network
  • Heap growth leading to OutOfMemory crashes
  • ANRs (Application Not Responding) on the main thread
  • Jank and dropped frames during scroll or animation
  • Unbatched or excessive network calls
Lens Studio — AR effects
  • Tracking drop-outs during device preview
  • Textures and assets over the device memory budget
  • Script-side performance causing tracking lag
  • Frame rate warnings on lower-end target devices
Meta Quest Developer Hub — standalone VR/MR
  • Dropped frames triggering Asynchronous Space Warp
  • CPU/GPU utilisation imbalance
  • Thermal throttling on extended sessions
  • Tracking loss and boundary system errors
